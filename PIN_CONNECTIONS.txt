================================================================================
                    EXACT PIN-TO-PIN CONNECTIONS
================================================================================

TRANSMITTER BOARD
================================================================================

OLED Display (4 pins in order: GND, VCC, SCK, SDA)
---------------------------------------------------
Pin 1: GND  ───────> ESP32-C3 GND
Pin 2: VCC  ───────> ESP32-C3 3.3V
Pin 3: SCK  ───────> ESP32-C3 GPIO7  (I2C Clock)
Pin 4: SDA  ───────> ESP32-C3 GPIO6  (I2C Data)


Joystick 1 (5 pins in order: GND, 5V, VRX, VRY, SW)
---------------------------------------------------
Pin 1: GND  ───────> ESP32-C3 GND
Pin 2: 5V   ───────> ESP32-C3 5V  (or 3.3V)
Pin 3: VRX  ───────> ESP32-C3 GPIO0  (Analog X-axis)
Pin 4: VRY  ───────> ESP32-C3 GPIO1  (Analog Y-axis)
Pin 5: SW   ───────> ESP32-C3 GPIO2  (Button)


Joystick 2 (5 pins in order: GND, 5V, VRX, VRY, SW)
---------------------------------------------------
Pin 1: GND  ───────> ESP32-C3 GND
Pin 2: 5V   ───────> ESP32-C3 5V  (or 3.3V)
Pin 3: VRX  ───────> ESP32-C3 GPIO3  (Analog X-axis)
Pin 4: VRY  ───────> ESP32-C3 GPIO4  (Analog Y-axis)
Pin 5: SW   ───────> ESP32-C3 GPIO5  (Button)


Built-in LED
---------------------------------------------------
GPIO8 (no wiring needed - built into board)

RECEIVER BOARD
================================================================================

OLED Display (4 pins in order: GND, VCC, SCK, SDA)
---------------------------------------------------
Pin 1: GND  ───────> ESP32-C3 GND
Pin 2: VCC  ───────> ESP32-C3 3.3V
Pin 3: SCK  ───────> ESP32-C3 GPIO7  (I2C Clock)
Pin 4: SDA  ───────> ESP32-C3 GPIO6  (I2C Data)


================================================================================

IMPORTANT NOTES
================================================================================

1. SCK = SCL (both mean I2C Clock)
   Your OLED displays label it "SCK"
   Most documentation calls it "SCL"
   They are the SAME signal!

2. Pin order matters!
   Connect pins in order from left to right
   Don't skip or swap pins

3. Power connections:
   - OLED uses 3.3V (not 5V!)
   - Joysticks can use either 5V or 3.3V
   - Using 5V gives full analog range (recommended)

4. Ground connections:
   - All GND pins must connect to ESP32 GND
   - You may need to use a breadboard to share GND

5. Code is already configured correctly:
   - GPIO6 → SDA (data)
   - GPIO7 → SCK/SCL (clock)
   - Do NOT modify the code
